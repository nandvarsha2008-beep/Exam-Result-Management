1. Introduction
The Exam Result Management System is a simple Python project that allows users to add student examination records, view all student results, calculate total marks and percentages, and generate a rank list.

The system manages marks for three subjects: Maths, Physics, and Chemistry. Each subject carries 100 marks, and a student must score at least 40 marks in every subject to pass.

Student records are stored permanently in a file named results.txt using JSON format.

2. Objectives
To store student examination records.
To calculate total marks and percentage automatically.
To determine whether a student has passed or failed.
To display all student results.
To generate a rank list based on percentage.
To prevent duplicate roll numbers.
To validate student details and marks.
To save and load student records using file handling.
3. Python Concepts Used

Concept	Description
Lists	Store marks and multiple student records.
Dictionaries	Store student details and examination results.
Functions	Perform different operations such as adding, viewing, and calculating results.
Loops	Display the menu and process student records.
Conditional Statements	Check pass/fail status and validate input.
Sorting	Arrange student records according to percentage.
File Handling	Save and retrieve student records from a file.
JSON	Store student records in JSON format.
Exception Handling	Handle invalid input and file-related errors.
4. Main Features
1. Add Student Result
Allows users to enter a student's roll number, name, and marks in three subjects.

2. View All Results
Displays all student records, including roll number, name, total marks, percentage, and result.

3. Calculate Result
Automatically calculates total marks and percentage and determines whether the student has passed or failed.

4. Rank List
Displays students in descending order according to their percentages.

5. Duplicate Roll Number Validation
Prevents users from adding another student with an already existing roll number.

6. Marks Validation
Ensures that marks entered for each subject are between 0 and 100.

7. File Handling
Saves student records in results.txt and loads previously saved records when the program starts.

5. Marks and Result Details
Total Subjects: 3
Subjects: Maths, Physics, and Chemistry
Maximum Marks per Subject: 100
Total Maximum Marks: 300
Passing Marks per Subject: 40
Percentage Calculation: (Total Marks / 300) × 100
Pass Condition: At least 40 marks in every subject.
Fail Condition: Less than 40 marks in any subject.
